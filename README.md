# TCGdex Pokémon Card Browser

Petite application web permettant de rechercher des cartes Pokémon, parcourir les résultats et télécharger leurs visuels en haute définition.

Le projet utilise l’API TCGdex pour récupérer les données et les images des cartes.

## Fonctionnalités

- Recherche de cartes Pokémon par nom
- Autocomplétion côté client
- Affichage paginé des résultats
- Prévisualisation optimisée des cartes
- Téléchargement des images en haute définition
- Interface responsive

## Stack

- Python
- Django
- JavaScript
- HTML
- CSS
- API TCGdex

## Fonctionnement

La recherche est gérée côté Django.

Les cartes sont récupérées depuis TCGdex, puis préparées côté serveur avant d’être affichées dans l’interface.

Le JavaScript gère principalement l’autocomplétion des noms de cartes pour rendre la recherche plus fluide.

## Contexte

Projet personnel réalisé pour expérimenter l’intégration d’une API externe, la recherche dynamique et la manipulation d’images dans une petite application Django.
